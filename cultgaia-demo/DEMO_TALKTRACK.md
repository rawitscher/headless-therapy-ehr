## Architecture cheatsheet (for the technical buyer)

| Layer | What | Where |
|---|---|---|
| UI | React 19 + Tailwind + shadcn/ui | `force-app/main/default/uiBundles/CultGaiaConsole/src/` |
| Branding | CSS variables + Cormorant Garamond + Inter | `src/styles/global.css` |
| Hero page | `Customer360.tsx` with 5 tabs | `src/pages/Customer360.tsx` |
| Live data bridge | Real Contact IDs in `salesforceContactId` | `src/data/demoData.ts` |
| Agent widget | `<AgentforceConversationClient agentId="0Xx710000000TgLCAU" />` | `src/appLayout.tsx` |
| Agent | Hub-and-spoke with 3 subagents | `force-app/main/default/aiAuthoringBundles/CultGaiaCopilot/CultGaiaCopilot.agent` |
| Custom fields | 8 fields on Contact | `force-app/main/default/objects/Contact/fields/` |
| Permission set | `CultGaia_Demo_Admin` (grants FLS) | `force-app/main/default/permissionsets/` |
| Automation | Daily-triggered Flow | `force-app/main/default/flows/Notify_Manager_On_VIP_At_Risk.flow-meta.xml` |

## Known demo-day gotchas

- **FAB doesn't appear** → check `CopilotSalesforceUser` perm set is assigned to the demo user. Also confirm My Domain → Cookies → "Require first-party use of Salesforce cookies" is **unchecked**.
- **Salesforce link 404s** → the Contact got deleted (it's a scratch org — they expire). Re-run `sf data import tree --files data/contacts.json -o cultgaia-scratch` and re-patch the IDs into `demoData.ts`.
- **Agent says "Something went wrong"** → a subagent got deactivated. Open Agent Builder, verify all three subagents (`customer_recap`, `personalized_outreach`, `daily_priorities`) show Active.
- **`sf agent preview` errors with "Invalid user ID"** → expected for Employee Agents. The deployed widget still works.

## What's NOT in this build (so don't promise it)

- Live GraphQL data — only the Customer 360 Salesforce-link is live; KPIs and order rows are static
- Working chat *outside* the deployed bundle URL — localhost dev was blocked by CSP `frame-ancestors`; demo from the deployed URL only
- Live MCP / Claude integration — skipped per the skill's recommendation (OAuth flow is flaky as of mid-2026)
- Person Account model — Contact-only

If the buyer pushes for any of these, scope them into the pilot SOW, not the demo.
